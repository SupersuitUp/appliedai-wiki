# State

*The agent reads this first, every time. It holds ONLY what cannot be derived.*

**Run `python3 check.py` before trusting this file.** Counts and dates are
computed from the repo by that script, deliberately not typed here, because a
hand-typed count is wrong the day after it is written and it is wrong inside the
one file the whole pattern tells you to trust.

**If this file and the filesystem disagree, THE FILESYSTEM WINS.** Correct this
file, do not correct your memory of it.

**Phase:** <e.g. gathering sources | drafting | revising | submitted>

## Next action

The single next thing. One item, small enough for one sitting. If this says
"work on the thesis", it is wrong and needs breaking down.

Before accepting it, check it against Open questions below: a decision with a
nearer date outranks a chore, and the nearest dated commitment usually IS the
next action.

## Open questions

Undecided things, each with the date it must be decided by. An open question
whose date is nearer than the next milestone is not a question, it is the next

## Done

Newest first. Keep it, do not prune. This is how the project proves progress on a
day when it does not feel like there has been any.

## Unknown

Things nobody has established yet. Writing UNKNOWN here is correct and expected;
guessing is not. Each line should name what would resolve it.
