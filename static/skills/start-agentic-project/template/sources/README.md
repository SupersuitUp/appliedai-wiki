# Sources

One folder per source. The rule: **if it took effort to find, it goes in here.**

    sources/<slug>/
      raw.<ext>        the thing itself: pdf, transcript, email export, screenshot
      annotation.md    YOUR notes on it, dictated not typed
      meta.json        where it came from, when, why it matters

`annotation.md` is the part that matters. A raw source is a rock; an annotated
source is an ingredient. An agent given fifty annotated sources will assemble
something. An agent given fifty PDFs will summarise, which is worse.

Write the annotation as: what is in it, what is useful, what you disagree with,
and which part of the deliverable it serves. Dictate it. Volume and honesty beat
prose.
